# CMS Front-end Display Builder

ระบบหลังบ้านสำหรับตั้งค่าหน้า **Universal Content Listing** ที่ใช้ได้กับ Job, Blog, News, Product และ Download

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิดเบราว์เซอร์ที่ URL ที่ Vite แสดง (ปกติ `http://localhost:5173`)

## สิ่งที่ทำได้

- **Listing** — Search, Filter, จำนวนคอลัมน์, Pagination
- **Card** — เปิด/ปิด Thumbnail, Title, Description, Category, Location, Price/Salary, Status, CTA และเลือกรูปแบบ Media Top / Horizontal / No Media
- **Detail Page** — กำหนดบล็อกที่แสดงบนหน้ารายละเอียด
- **SEO & Publishing** — Title, Slug, Meta Description, Index, Publish
- **Live Front-end Preview** — Desktop / Mobile และสลับ Listing ↔ Detail

ทุกสวิตช์มีคำอธิบายสั้นๆ ว่าส่งผลต่อหน้าบ้านอย่างไร
